## 建议开关

- 保持 Issues 开启
- 开启 Discussions，用于安装帮助、体验反馈和玩法讨论
- 开启 Private vulnerability reporting
- 准备产品页后填写 Homepage
- 上传 1280×640 社交分享图，画面只保留图标、产品名和一句话价值

## 发布前检查

- 仓库首页首屏能看到价值、平台限制、下载和反馈入口
- Release 页面有真实兼容性、未签名提示和已知问题
- Topics、Description、Homepage 与 README 用同一套定位
